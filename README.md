# CIVINET

**Keep every community connected.**

CIVINET is a concept platform for resilient civic connectivity. It explores how telecom networks, public facilities and local communities could work together to keep essential information moving when conventional communication becomes unreliable.

## Website

The website is a standalone, responsive HTML prototype. It includes:

- CIVINET concept and problem overview
- Platform architecture and core capabilities
- Stakeholder ecosystem
- Nokia-relevant networking foundation
- Interactive network-outage and rerouting simulation

## Run locally

Open `index.html` in a modern web browser. No build tools or dependencies are required.

## Deployment

This repository is structured for GitHub Pages:

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. GitHub Pages will publish the site at the repository's Pages URL once deployment completes.

## Prototype limitations

The network map and outage simulator use illustrative, client-side data. This prototype does not connect to live telecom networks, Nokia Network as Code APIs, municipal systems or emergency services. Those integrations would require operator access, partner agreements, secure infrastructure and appropriate privacy safeguards.
